Sobre formulários

O que são formulários?

Os formulários são uma das partes mais importantes do nosso HTML semântico. Ele serve para:

  • Entrada de dados
  • Interação
  • Acessibilidade
  • Validação e envio de informações

Como trabalhar com um formulário no HTML

Para começarmos a trabalhar com um formulário dentro do HTML, utilizamos o elemento <form> .

Esse elemento, representa um formulário interativo.
